# The Spear

**The Spear** is a historical Spycraft-era creative project preserved as part of the wider Unknown Shores Studio archive.

This repository is a **public project home and historical reference surface**. It is intentionally lightweight while the underlying source material, drafts, and lineage are being recovered and classified through the private Creative Works Archive.

## Current status

The repository should not be read as a complete publication package yet.

Historical source recovery and provenance work for The Spear are tracked privately so that drafts, reference material, and version history can be separated cleanly before anything is promoted here as a current public artifact.

## Relationship to Unknown Shores

The Spear is maintained by the same creator and Studio ecosystem as Unknown Shores, but it is a distinct project.

For the current Unknown Shores campaign setting:

- https://www.unknownshoresrpg.com
- https://www.worldanvil.com/w/unknownshoresrpg

## What belongs here

As the project is reconstructed, this repository may eventually hold selected public-facing material such as:

- project documentation
- cleaned historical notes
- publication-safe reference material
- selected scripts, utilities, or supporting files
- release notes and project history

Private source packages, purchased RPG books, recovery evidence, and material whose rights or provenance are not yet settled do not belong in this public repository.

## Rights and provenance

Historical project material may come from multiple working eras and source formats. A filename or date alone does not establish which version was final, canonical, or publication-ready.

Public material will be added here only after its provenance and release status are clear.
