# Contributing

The Spear is a historical creative project currently being reconstructed from older source material.

Public contributions should therefore stay narrow and provenance-aware.

## Useful contributions

Useful contributions include:

- reporting a broken public file or repository link;
- correcting clear documentation errors;
- adding verifiable historical context;
- improving repository documentation or accessibility;
- identifying a public artifact whose provenance or release status is described incorrectly.

## Please do not upload

- private recovery packages or unreleased drafts;
- purchased Spycraft or other commercial RPG books;
- credentials, personal contact information, or private records;
- reconstructed or generated material presented as an original historical source.

## Historical material

A newer-looking file is not automatically the authoritative version. The private Creative Works Archive preserves the detailed recovery and provenance work behind this project.

If a proposed change depends on historical source evidence, explain that evidence rather than selecting a preferred version from filename or date alone.

## Pull requests

Keep changes focused and public-safe. If the status of a source is uncertain, open an issue rather than publishing it into this repository.
